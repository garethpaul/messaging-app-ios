# Makefile Path Syntax Rejection

status: completed

## Problem

The Make authority test used a checkout path containing `$()` and expected the
repository to fail closed without executing it. On current `master`, GNU Make
evaluated the path text while deriving `ROOT`, created the hostile marker, and
only failed later when the truncated path reached `shasum`.

## Design

- On GNU Make 4+, inspect the raw `MAKEFILE_LIST` value before any repository
  `$(shell ...)` root logic.
- Reject literal `$(` and `${` Make syntax without recursively expanding it.
- Apply the same policy to the live Makefile and every authenticated expected
  Makefile generated by the checker, tests, runner, and validation root.
- Preserve spaces and literal apostrophes in otherwise safe absolute paths.

## Test-First Evidence

The existing hostile `$()` test reproduced command execution against untouched
`master`. Its expected pre-expansion rejection was tightened before the Makefile
fix. A second `${` path case was added after the boundary was implemented.
Hosted macOS then demonstrated that GNU Make 3.81 expands the filename while
populating `MAKEFILE_LIST`, before any loaded Makefile rule can reject it. The
final regression uses an actual `$(shell ...)` payload on GNU Make 4+ and skips
the impossible in-Makefile assertion on 3.81.

## Verification

- Focused `$()` and `${` path tests passed with GNU Make 4.3 and skip on GNU
  Make 3.81, where the path has already expanded before repository code runs.
- `python3 -m unittest discover -s tests -p 'test_*.py'` passed 80 tests with
  two `--eval` cases skipped because the host Make lacks that option.
- Root and external-directory `make check` passed the authenticated
  pre/test/baseline/post chain.
- A hostile external `$()` marker probe failed with the new pre-expansion error
  and did not create its marker.
- `python3 scripts/check-baseline.py` and `git diff --check` passed.
- Xcode project parsing was skipped because `xcodebuild` is unavailable.

Native application behavior remains outside this Make authority change.
